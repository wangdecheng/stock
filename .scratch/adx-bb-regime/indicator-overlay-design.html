股票详情页 · ADX+BB 指标叠加

把 StateMachine 的 6 个原始信号 + TrendState/HalvedStage 两条状态色带画到 K 线图上,使「图」与「策略」完全对齐

Spec 来源: 本方案由 grill-with-docs 经过 3 轮共 9 个问题收敛得到,所有决策已锁定,无未决项。配套 3 份 ADR: 0006 panel layout B · 0007 state replay 纯函数 · 0008 build_volume deprecated。

① 摸清现有服务

本方案是已有服务上扩展,不是新建。所有涉及的模块已经在仓库中:

模块路径职责
图表层framework/charts/__init__.pyPyecharts + Grid 包装,提供 build_kline / build_volume / build_kline_volume_grid
指标层framework/indicators/__init__.py9 个指标(ma / bollinger / rsi / adx 等)的纯 pandas 实现 + 注册表

通信方式: Streamlit page → 直接调用 framework.charts(同进程);指标由 framework.indicators 直接 import 后调用,不经过 Context。

无外部服务依赖、无消息队列、无存储新增。

③ 数据模型

本方案不新增任何数据库表或持久化文件。所有数据流都是「内存里的 pd.DataFrame / pd.Series」在 Streamlit 单次 render 内完成。色带不需要落盘 —— 重渲染时由纯函数重新计算。

⑤ 安全设计

本方案是纯前端渲染层的扩展,无新接口、无新表、无新缓存、无新鉴权点。安全审查项目:

类别检查结论
输入校验用户输入 symbol / 时间范围已由既有 _fetch_bars_cached 处理(EmptyBarsError / UnknownSymbolError / DataAdapterUnavailable / RateLimitExceeded),本方案不引入新输入
存储安全无新写入路径N/A —— 全部内存计算,色带不持久化
访问控制无新接口N/A —— 仍是单用户本地 Streamlit
传输安全无新增网络N/A —— 沿用既有 AKShare adapter 链路
并发 / 资源每根 bar 4 个指标 + 1 个回放60 根 bar 单次 render ~30ms,Streamlit rerun 触发频率无变化(form gate 已就位)
副作用隔离历史回放函数必须不写 ctx.state由 API 设计保证(纯函数 df → Series),且 parity test 跑在隔离的 fake Context 上不会污染
注意 (非安全风险,是设计约束): 历史回放必须严格用 「按日闭式」假设(close_t 已知,推算 state_t),不允许偷看未来 bar。本方案的 _classify_series 内部只用 iloc[i] 截面的指标值,不存在 look-ahead bias;parity test 用一段真实 60-bar 历史跑回归,确认无未来信息泄漏。
